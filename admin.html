      Students

      Each student needs a name and grade — the programme (EYP/PYP) is set automatically. Family is optional but recommended: it auto-fills the Family field on that student's card(s) in the Cards tab. Students don't have their own scan code anymore; a pickup card (next tab) is what gets scanned. Click a column header to sort A–Z (click again for Z–A).

      Import / export (Excel)

      One sheet, one row per student: Name, ID, Grade, Family, Card Codes, Guardians. Easiest path: just fill in Family and Guardians and leave Card Codes blank — a card is created automatically for each family + guardian combination, so you never have to set anything up in the Cards tab by hand. Give siblings the same Family and Guardian to share one auto-created card. If you want a specific code instead (e.g. to match a pre-printed card), fill in Card Codes yourself — for more than one guardian card on the same student, separate codes with semicolons (e.g. "FAM002; FAM003") with the matching guardians in the same order (e.g. "Mr. Xiong; Mrs. Xiong"), still just one row. Download a blank template to start from scratch, or export your current students and cards to edit in bulk. Upload the file back here when you're done — uploaded rows are added to both tables for review, and nothing is saved until you click Save students / Save cards.

      Pickup cards

      Each card is what actually gets scanned. Give it a code and the guardian's name, then use "Edit students" to pick who it covers — Family fills in automatically from the students' Family field on the Students tab. If a family has students in both EYP and PYP, use "Add whole family…" inside Edit students to add all of them to one guardian's card in one click. If several guardians each carry their own card for the same kids (e.g. Mom, Dad, Grandma), just add one card per guardian and pick the same students (or family) on each. If a card is lost, just remove it here; the student's record is untouched, and you can add them a new card. Click a column header to sort A–Z (click again for Z–A).

      Staff & bus cards

      Each staff or bus card is its own row — one code per person, no separate cards step needed like Students has. Type is either Staff or Bus. These cards scan through the same Scan station and security gate as pickup cards; the system tells them apart automatically. Click a column header to sort A–Z (click again for Z–A).
