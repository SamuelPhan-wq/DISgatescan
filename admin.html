      Bulk add students

      One student per line: ID, name, grade (Nursery, PreS, Pre-K, Kinder, G1, G2, G3, G4, G5). The ID can be anything unique — a student number works well.

      Pickup cards

      Each card is what actually gets scanned. Give it a code, the guardian's name, and pick the student(s) it covers — hold Ctrl/Cmd to select more than one for siblings. If a card is lost, just remove it here; the student's record is untouched, and you can add them a new card.
